# Releases

One document per production release, kept here and committed with the code.

- **Template:** [TEMPLATE.md](TEMPLATE.md)
- **Naming:** `YYYY-MM-DD-vX.Y.Z.md` (date = planned deploy day). Versions follow semver; tag the release commit `vX.Y.Z`.
- **When:** create the document before deploying, from the template, and finish section 8 (Outcome) afterwards. A release without a document has not happened.
- **Scope:** a release document only records what is specific to that release. Server setup and the generic procedures stay in [DEPLOYMENT.md](../../DEPLOYMENT.md) so they are not duplicated.
